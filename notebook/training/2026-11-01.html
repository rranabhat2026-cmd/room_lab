Recognize

  • SPF — safety performance function: predicted crashes per year for a site type as a function of traffic volume and geometry.
  • EB — Empirical Bayes estimate: weighted average of the SPF prediction and the site's observed crashes.
  • k — negative binomial overdispersion parameter: how much more crash counts vary than a Poisson process would.
  • RTM — regression to the mean: sites picked for high counts tend to show lower counts next period even with no treatment.
  • CMF — crash modification factor: expected crashes after / before a countermeasure (0.8 means 20% fewer).
  • HSM — Highway Safety Manual (AASHTO); Part B covers network screening and evaluation.
  • Wardrop UE — user equilibrium: no driver can lower their travel time by switching routes.
  • Relative gap — (total system travel time − demand × shortest-path time) / total system travel time; zero at exact UE.
  • MCP — Model Context Protocol: a standard way for an LLM to call external tools such as a planning engine.
  • Manufactured solution — a chosen exact answer used to test a numerical method, because the truth is known.

Understand 1 · The residual tells you about the physics, not the data

Intuition: data error asks 'do I match the measurements?'; physics residual asks 'do I satisfy the governing equation?'. A model can pass one and fail the other.

Setup (from the starter): truth u*(x) = sin(πx) + 0.25 sin(3πx); model û(x) = sin(πx) + â sin(3πx); equation u'' = f(x) with f(x) = −π² sin(πx) − 9π²(0.25) sin(3πx).

Worked derivation: û''(x) = −π² sin(πx) − 9π² â sin(3πx). Therefore R(x) = û''(x) − f(x) = −9π²(â − 0.25) sin(3πx). The residual is zero exactly when â = 0.25.

Worked number: over [0, 1] the mean of sin²(3πx) is 1/2, so residual MSE = 81π⁴(â − 0.25)²/2. For â = 0.30 that is 81 × 97.409 × 0.0025 / 2 ≈ 9.86 (checked numerically: 9.86).

Why it matters for traffic: in LWR the residual is ∂ρ/∂t + ∂q/∂x. A forecaster with small data error can still create or destroy vehicles, and the residual exposes it.

Limitation: a small residual only means 'consistent with this equation'. If the equation is wrong for the regime (incidents, capacity drop), a perfect residual is false comfort. Simpler alternative: a conventional finite-difference solve is often enough when the equation and boundary conditions are known.

Understand 2 · Empirical Bayes: shrink toward what similar sites do

Intuition: a site with 12 crashes in 3 years looks terrible, but part of that is bad luck. EB asks how much to trust the site's own history against what similar sites usually experience.

Formulation (HSM Part B style): over n years, the SPF predicts Σμ crashes. With overdispersion k, the weight w = 1 / (1 + k·Σμ). The EB expected crashes are N_exp = w·Σμ + (1 − w)·N_obs. Units: crashes over the same n years.

Worked example (checked): Σμ = 6.0 crashes in 3 years, k = 0.5, N_obs = 12. w = 1/(1 + 0.5 × 6) = 0.25. N_exp = 0.25 × 6 + 0.75 × 12 = 10.5 crashes, i.e. 3.5 per year instead of the raw 4.0.

Reading the weight: large k (counts are noisy) or a large Σμ (much expected exposure) pushes w down, so you trust the site's own record more. That is not intuitive at first; you will derive why in Task 2.

Application: rank sites by N_exp − Σμ (excess expected crashes), not by raw counts. For before/after studies, EB corrects the RTM bias that makes almost any treatment look effective at a site chosen after a bad year.

Limitation: EB is only as good as the SPF; an SPF from another state needs a local calibration factor. Simpler alternative: for quick screening, crash rate per million entering vehicles is acceptable if you say it ignores RTM.

Understand 3 · User equilibrium and the relative gap as a verifier

Intuition: at equilibrium every used route between an origin and destination takes the same time, and no unused route is faster.

Worked example (checked): 1000 veh/h, route 1 time t1 = 10 + 0.01·x1 min, route 2 time t2 = 15 + 0.005·x2 min. Setting t1 = t2 with x1 + x2 = 1000 gives 0.015·x1 = 10, so x1 ≈ 666.7, x2 ≈ 333.3, and both routes take ≈ 16.67 min. Relative gap = 0.

Off-equilibrium check: x1 = 800, x2 = 200 gives t1 = 18, t2 = 16. Total time = 800·18 + 200·16 = 17,600 veh·min; demand × shortest = 1000·16 = 16,000; gap = 1,600 / 17,600 ≈ 0.091.

Why a verifier loves this: the gap can be recomputed from link flows and travel-time functions alone, without trusting whatever produced the flows, including an LLM.

Limitation: a zero gap proves equilibrium for the network you were given, not that the network edit was the one the planner asked for. That second check needs a spec of the intended edit.

Task 1 · Coding: Verified Physics Residual Lab (20 pts · 2.5 h · P3/P4)

Build it in Python with NumPy (and Matplotlib for one plot). Fixed seeds 0–9; sample sizes n ∈ {10, 50}; noise σ ∈ {0.01, 0.1}; points xᵢ uniform on [0, 1] from the seeded generator.

Deliverables: (a) fit.py estimates â by least squares and writes results.csv (seed, n, σ, â, data MSE, residual MSE on a 1,001-point grid, boundary error); (b) baseline.py solves u'' = f with u(0) = u(1) = 0 by second-order finite differences on 101 points and reports max error against u*; (c) verify.py independently recomputes every metric from the saved inputs and prints PASS / FAIL / UNKNOWN per row; (d) one plot of â error versus n and σ.

Deliberate failure cases verify.py must handle: a row where you edit â by hand (FAIL); a missing input file (UNKNOWN); a design where every xᵢ is in {0, 1/3, 2/3, 1}, so Σφᵢ² = 0 and â is undefined (UNKNOWN, not a crash or a number).

Acceptance: mean â within 2 standard errors of 0.25 for every (n, σ); verifier verdicts correct on all three failure cases; finite-difference max error below 1e-3; README states exactly what was run.

# skeleton — fill in, do not just run
import numpy as np

def design(seed, n):
    return np.sort(np.random.default_rng(seed).uniform(0, 1, n))

def a_hat(x, y):
    phi = np.sin(3 * np.pi * x)
    denom = np.sum(phi ** 2)
    if denom < 1e-12:
        return None  # undefined: the verifier should say UNKNOWN
    return np.sum(phi * (y - np.sin(np.pi * x))) / denom
